Privacy Policy

Last updated November 17, 2026

This policy covers the Respawn Gear Co website and Respawn Gear Co Automation, the private tool we use to send videos to our own TikTok account (@respawngearco).

What the tool gets from TikTok

When we connect our TikTok account, TikTok shares only what the tool needs to post:

  • Basic profile info (user.info.basic): the account's ID, display name and profile picture, so we know which account is connected.
  • Permission to upload drafts (video.upload): so the tool can send our own videos to our TikTok drafts.

The tool only ever connects to our own account. It doesn't read anyone else's profile, videos, followers or messages.

How it's stored

The sign-in key TikTok gives the tool is kept on our own private server at home. It isn't sold, shared or given to anyone. We keep it only as long as the tool is connected.

This website

This site doesn't use cookies, ads or tracking. It's hosted by GitHub Pages, which may keep basic server logs (like IP addresses) as described in GitHub's own privacy policy.

Removing access

Access can be removed at any time from the app permissions list in the TikTok app's privacy and security settings. Once removed, the tool can't send anything.

Questions

Email respawngearco@gmail.com and we'll answer, or delete anything we have, on request.
